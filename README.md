## Project Overview

โปรเจกต์ **IOT-MP3-Players** เป็นระบบเครื่องเล่นเพลง MP3 อัจฉริยะที่เชื่อมต่อกับอินเทอร์เน็ตผ่านแนวคิด **IoT (Internet of Things)** โดยพัฒนาขึ้นสำหรับวิชา Physical Computing ของคณะเทคโนโลยีสารสนเทศ สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง (KMITL)

### Objectives
1. เพื่อประยุกต์ใช้ความรู้ด้านไมโครคอนโทรลเลอร์ เซนเซอร์ และการสื่อสารไร้สายในการสร้างสรรค์ฮาร์ดแวร์อัจฉริยะ
2. เพื่อศึกษาและใช้งานโปรโตคอล MQTT สำหรับการรับ-ส่งข้อมูลและควบคุมอุปกรณ์ IoT แบบ Real-time
3. เพื่อบูรณาการการควบคุมฮาร์ดแวร์เข้ากับระบบเว็บหรือแพลตฟอร์มออนไลน์ผ่านเครือข่ายอินเทอร์เน็ต

## System Architecture & Features

ระบบนี้เป็นการผสมผสานระหว่าง **Embedded Hardware** และ **IoT Network** โดยมีฟังก์ชันหลักดังนี้:

* **การเล่นเพลง (MP3 Playback):** ควบคุมการเล่นเพลง เล่นซ้ำ หยุดชั่วคราว (Pause/Resume) เปลี่ยนเพลงก่อนหน้า-ถัดไป ผ่านโมดูล **DFPlayer Mini** ที่อ่านไฟล์เสียงจาก MicroSD Card
* **ระบบควบคุมระยะไกลผ่าน MQTT (MQTT Control):** สามารถสั่งการเครื่องเล่นเพลงผ่าน Broker (เช่น HiveMQ) รองรับหัวข้อคำสั่ง (Topics) เช่น:
  * การกด Play/Pause/Skip เพลง
  * การเลือกเพลงจาก Playlist
  * การปรับโหมด Equalizer (Normal, Pop, Rock, Jazz, Classic, Bass)
* **การแสดงผลและควบคุมโดยตรงบนฮาร์ดแวร์ (Local Controls):**
  * **หน้าจอ LCD I2C:** แสดงชื่อเพลงปัจจุบัน สถานะการเล่น และระดับเสียง (Volume)
  * **Potentiometer (วอลุ่มปรับเสียง):** หมุนปรับระดับเสียงของเครื่องเล่นได้ทันที
  * **Push Buttons:** ปุ่มกดควบคุมการทำงานแบบ Manual (Prev, Play/Pause, Next)
* **Status LEDs:** แสดงสถานะการทำงานของระบบ เช่น สถานะการเชื่อมต่อ Wi-Fi/MQTT, สถานะกำลังเล่นเพลง หรือสถานะหยุดชั่วคราว
